# Descripción de la validación experimental

La validación del DPVAD_SAT se realizó en una ventana experimental comprendida entre el **21 y el 28 de julio de 2026 (UTC−5)**.

Se analizaron tres fuentes principales de evidencia:

1. registros locales persistidos en microSD;
2. exportación de telemetría desde ThingSpeak;
3. logs operativos del sistema.

Las pruebas incluyeron condiciones controladas de disponibilidad, intermitencia e indisponibilidad de conectividad para observar el comportamiento de los modos ONLINE, OFFLINE y BACKFILL.

ThingSpeak se utilizó como plataforma de recepción y visualización remota. MATLAB se utilizó como herramienta complementaria para análisis y representación de los datos.

Los resultados deben interpretarse dentro del alcance de una validación funcional controlada y no como evidencia suficiente para generalizar desempeño rural, exactitud metrológica o comportamiento operacional prolongado.
