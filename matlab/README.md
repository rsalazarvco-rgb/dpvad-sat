# MATLAB

MATLAB se utilizó como tecnología complementaria para análisis y representación de datos dentro del ecosistema de ThingSpeak/MathWorks.

## Alcance del material publicado

La V6 no incorpora código fuente de scripts MATLAB como anexo. Por rigor académico, este repositorio no inventa scripts que no estén disponibles como fuente original.

Cuando los scripts originales estén disponibles, deben incorporarse indicando:
- nombre del script;
- fuente de entrada;
- variables procesadas;
- versión/toolboxes;
- figura o tabla producida.
