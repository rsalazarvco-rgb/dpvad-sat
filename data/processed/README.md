# Datos procesados

Este directorio debe contener exclusivamente archivos derivados de los datos originales.

Ejemplos:

- conciliaciones local/remoto;
- métricas de completitud;
- análisis de unicidad;
- análisis temporal;
- resultados BACKFILL;
- datasets agregados para figuras.

Cada archivo procesado debe documentar su origen y el procedimiento utilizado para generarlo.
